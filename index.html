大タスクの提案
季節と、これまでのタスクから考えます。いらない案は左にスワイプで消せます。

屋外の小タスクは、降水確率が設定値未満の日にだけ入れます。カレンダーの空き状況は見ていないので、時間は各自で調整してください。

Googleのページをそのまま表示しているだけで、このツールやAIは中身を読めません。表示されない場合は「Googleカレンダーを開く」を使ってください。

Google Gemini API

タスク名・メモ・期限と、下の指示文だけを送ります。キーはこの端末のブラウザにだけ保存されます。

無料枠では、送った内容がGoogleのサービス改善に使われることがあります。

検索を使うと、タスクの内容が検索語としてGoogle検索にも送られます。検索の無料枠を超えると、自動で検索なしに切り替えます。

カレンダー表示

表示専用です。予定の内容はこのツールにもAIにも渡りません。色はカレンダーごとに付けられます。予定ごとに個別に付けた色は、Googleの埋め込み表示では反映されません。
使える色の例: #039BE5 青 / #33B679 緑 / #F6BF26 黄 / #F4511E 橙 / #D50000 赤 / #8E24AA 紫 / #616161 灰

天気(Open-Meteo)

送るのは緯度経度だけです。タスクは送りません。
